Lagsregisteret

Kjelde: Alle rader i tabellen kjem frå organisasjonar som er med i frivillighetsregisteret hjå Brønnøysundregistera (opne data), pluss lokale filtreringar i repositoriet (søkjefragment, utelatingsfrasar, ev. «norsk tilhald» ved innhenting). Dei tre Ungdom* / Grend* / Bygd*-knappane viser berre treff som vart funne med søkje­fragment frå høvesvis sokjefragment.txt, sokjefragment_grende.txt og sokjefragment_bygd.txt — ikkje «reine» typar i Brreg.

Søk i alle felt, snevre etter fylke og status, eller bruk Rediger i lista for å setja NU-status (medlem, potensiell medlem, utmeld, ikkje aktuell, nedlagt) og luka ut rett i tabellen — utan innlogging: endringar vert lagra lokalt i nettlesaren, og du kan lasta ned manuell_status.json når du vil sjekkja inn i repositoriet. Laga du lukar ut (ikkje ungdomslag / ikkje frilynde) er skjulte som standard — bruk avkryssinga for å sjå dei. Du kan også redigere data/manuell_status.json rett i git eller bruk skript/sett_lag_status.py; admin-sida er valfri (same som Vercel‑push, treng passord).

Brei tabell: dra vassrett under tabellen, eller bruk Tab + piltast / mus med skroll. Rader heilt i grøn tone = treff i lokallaglista (NU) jamførd med registret (nu: medlem), eller manuelt medlem. Gul tone = potensiell medlem — dempa = ikkje aktuell. Raud tone for utmeld eller nedlagt. Utmelding gjev føretré over grønt.
