NU: kopier mellom duplikat (to orgnr)

Når eit lag gjeld som to Brreg‑rader (same stad, UL og ungdomslag o.l.), kan du kopiere NU‑felt (Status, Ovanståande org., Org.type) frå ei rad til ei anna. Det vert lagra i denne nettlesaren og gjeld neste gang du lastar sida. Last ned JSON for å køyre python3 skript/bruk_medlemas_ul_jamfor_valg.py i depotet eller for handverk mot docs/data/lag.csv.

Aktive kopiar (som vert brukt att ved neste oppstart av sida):

    Endringar vert lagra i denne nettlesaren (ikkje på GitHub automatisk).
    Valfri: push til Git over Vercel (brukar og passord)

    Vel per rad. Fil vert lagra lokalt; last ned JSON for git, eventuelt push i feltet under.
